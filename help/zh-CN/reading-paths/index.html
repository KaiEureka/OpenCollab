设计新的 Workflow

理解 Workflow 的编程模型与自由度 → 判断 Workflow 能实现的范围与运行边界 → 编写第一个自定义 Workflow → 按开发任务查找 Workflow 公开 API → 设计 Workflow 的输入输出与步骤间数据流 → 在 Workflow 中调用 Agent 并处理结果 → 在 Workflow 中并行处理多项任务 → 理解 Agent、Team 与 Workflow 的调用层级 → 组合子 Workflow 并采用候选结果 → 处理 Workflow 的失败、重试与恢复 → 验证与调试自定义 Workflow

建立团队并派发任务

Team 完整指南与团队配置 → 派发 Agent 任务并安排审阅 → 向队友发消息并继续协作 → 等待队友结果并读懂团队状态 → 采用队友改动并验证交付 → 让 Team 成员调用已注册 Workflow → 让成员编写并管理自己的子 Workflow

理解与配置隔离

隔离怎么选 → 默认隔离与单次覆盖怎么配 → 多个任务怎样在独立工作区改代码 → 在容器中运行任务 → 让任务在指定目录或现有容器里执行 → 把候选结果采纳到交付目录 → 找回隔离任务的改动并清理资源

配置模型与运行参数

配置从哪里读取以及哪一项生效 → 配置参数与环境变量速查 → 接入模型端点与认证凭据 → 选择调用协议与流式响应 → 配置深度思考与采样参数 → 检查有效配置与定位常见启动故障

接入自己的应用服务

从 Python 调用 OpenCollab → 接入模型端点与认证凭据 → 逻辑模型路由与共享请求容量 → 从示例接入自己的服务 → 中断任务与检查资源清理 → 查看 Agent 做了什么 → 找到运行记录、会话和交付文件

理解原理与架构

一次任务如何从输入走到工具执行 → Session 如何保存进度并继续执行 → 理解 Workflow 的编程模型与自由度 → 判断 Workflow 能实现的范围与运行边界 → 隔离怎么选 → OpenCollab 负责什么以及如何扩展 → 检查团队是否真的按分工协作 → 用实际测试验证 Agent 的交付
